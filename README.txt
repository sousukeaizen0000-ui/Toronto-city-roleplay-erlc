TORONTO CITY ROLEPLAY WEBSITE
==============================

Files:
- index.html
- styles.css
- script.js
- assets/toronto_logo.png

GitHub Pages:
1. Upload all files/folders to your GitHub repository.
2. Go to Settings -> Pages.
3. Source: Deploy from a branch.
4. Branch: main
5. Folder: / (root)
6. Save.

IMPORTANT:
- Replace the Discord links in index.html with your real Discord invite.
- Replace the ER:LC link with your real server/join link.
- The verification button is currently a placeholder.
- Real Discord OAuth2 verification requires a secure backend.
- Never put a Discord bot token or OAuth client secret in index.html, styles.css, or script.js.

The gallery currently uses styled placeholders. Replace the gallery tiles with your own TCXRP screenshots when ready.
